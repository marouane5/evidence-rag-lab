# Demonstration data card

**Origin:** original, AI-assisted fictional examples authored for this repository on 16 November 2026. Atlas is an invented service, not a real company's policy manual. Source URIs beginning `demo://` are stable identifiers, not public web pages.

**Contents:** six policy/runbook topics, each with English and French records: log retention, incidents, backups, access reviews, API retries and deployment rollback. There are 12 records total, ten development questions and sixteen distinct test questions. Four test questions are deliberately unanswerable.

**License:** MIT, including demonstration corpus and query labels. No scraped company document, private candidate data, secret or personal information is required.

**Known bias:** short clean documents; aligned translations; a narrow vocabulary; queries authored by the same workflow as documents. These make the benchmark substantially easier than enterprise search. The split holds out questions, not organizations or topics. Perfect scores on this set do not establish robust retrieval.

**Adding data:** provide source links and permitted excerpts, preserve document IDs, maintain separate development/test query IDs, include negative questions with overlapping terminology, and record corpus changes before comparing runs. Do not publish private material accidentally through reports, which contain source text.
